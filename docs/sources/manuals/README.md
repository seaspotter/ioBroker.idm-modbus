# IDM installation manuals and data sheets (reference copies)

Evidence for [docs/idm-models-and-schemes.md](../../idm-models-and-schemes.md): the plant schemes ("Anlagenschemen"), sensor and output tables and
product data from IDM's installation manuals. Copyright IDM Energiesysteme GmbH. **The PDFs are kept locally only and are not committed** (the
repository is public; `.gitignore` excludes `docs/sources/manuals/*.pdf`), not part of the npm package, and not re-hosted. This table is the
manifest: it records which file is which document and where it was downloaded (2026-10-15), so the set can be fetched again.

Most files are copies hosted by third parties (dealers, mirrors), not IDM's own site. They are older editions than IDM's current partner
portal documents in places; the edition printed in each file counts. When a document contradicts a device scan, the scan wins (CLAUDE.md rule 5).
